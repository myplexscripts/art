# Tomb Atlas

Tomb Atlas is an independent Tomb Raider reference site covering games, films, television, books, comics, walkthroughs, characters, artifacts, galleries, technical help, and related media.

## Structure

- `index.html` contains the application shell.
- `styles.css` contains global tokens, typography, navigation, controls, and responsive foundations.
- `design.css` contains page composition and reusable content patterns.
- `app.js` contains archive data, routing, search, filters, and page rendering.
- `DESIGN_SYSTEM.md` is the source of truth for UI consistency.

The site is a client-side hash-routed prototype and is designed for both large screens and mobile.
